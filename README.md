# Halloween en el fraccionamiento 🎃

Encuesta para saber qué casas dan dulces, cuántos niños salen, quién entra al concurso de disfraces y quién viene a la película.

- `index.html` – la encuesta
- `lista.html` – lista pública de casas que dan dulces (no muestra datos de niños)
- `config.js` – aquí va la URL de la API de Apps Script

Los datos se guardan en un Google Sheet mediante Google Apps Script (`Code.gs`, que no va en este repositorio).
